# どうぶつビンゴ

## 同じ Wi-Fi で遊ぶ

Node.js 22 以上を使います。初回は、このフォルダで `cp -n .env.example .env` を実行すると初期パスワード `123456` が設定されます。変更するときは `.env` の `ADMIN_PASSWORD` を編集し、サーバーを再起動します。ngrokで公開する場合は、初期値から推測されにくいパスワードに変更してください。

```sh
node local.mjs
```

起動時に表示される「参加者用」の URL を、同じ Wi-Fi につないだスマホで開きます。PC では「管理画面」の URL を開き、`.env` に設定したパスワードでログインします。ホスト PC からスマホへの接続が許可されているネットワークで使用してください。

## ngrok でインターネットに公開する

ngrok はプロジェクトフォルダではなく、Mac 上で動いているサーバーのポートに接続します。同じ Mac でフォルダを移動した場合は、新しいフォルダからビンゴを起動してください。

### 初回だけ

ngrok が未インストールなら `brew install ngrok` を実行します。[Your Authtoken](https://dashboard.ngrok.com/get-started/your-authtoken) に表示される `ngrok config add-authtoken ...` のコマンドをターミナルで実行します。設定済みの Mac ではこの手順を飛ばせます。[ngrok 公式手順](https://ngrok.com/download/mac-os)

### 起動と共有

1. 公開前に `.env` の `ADMIN_PASSWORD` を初期値から推測されにくいパスワードに変更します。古いフォルダから起動したビンゴがあれば、先にそのターミナルで `Control + C` を押して停止します。

2. ターミナル1でビンゴを起動します。

   ```sh
   cd "$HOME/Desktop/アプリ開発/bingo"
   node local.mjs
   ```

3. ターミナル2で ngrok を起動します。

   ```sh
   ngrok http 8787
   ```

4. `Forwarding` に表示された HTTPS URL をスマホで確認し、参加者に共有します。管理者は Mac で [管理画面](http://localhost:8787/?admin) を開きます。両方のターミナルを開いたままにします。

### 変更したとき

| 変更内容 | 操作 |
| --- | --- |
| フォルダを移動した | 新しいフォルダから `node local.mjs` を実行します。ポートが同じなら ngrok 側の設定はそのまま使えます。 |
| コードや管理者パスワードを変更した | ビンゴを `Control + C` で止め、`node local.mjs` で再起動します。ポートが同じなら起動中の ngrok をそのまま使えます。 |
| ポートを変更した | `.env` に例として `BINGO_PORT=9000` を追加し、ビンゴを再起動します。ngrok も停止し、`ngrok http 9000` で起動します。管理画面は `http://localhost:9000/?admin` になります。 |

公開を終えるときは、ターミナル2で `Control + C` を押して ngrok を止め、続いてターミナル1でも `Control + C` を押します。[ngrok の HTTP エンドポイント](https://ngrok.com/docs/gateway/endpoints/http)

## テーマ

参加者はトップ画面で「どうぶつ」または「冬」を選びます。管理者は管理画面のテーマ切り替えから、素材・スタンプ候補・抽選履歴をテーマごとに管理します。両テーマには絵文字の初期素材が35種類ずつ入っています。

既存の動物素材・スタンプ・抽選履歴は「どうぶつ」に引き継がれます。端末に保存されたカードもテーマごとに再開できます。

## コード構成

| ディレクトリ | 役割 |
| --- | --- |
| `ui/` | ブラウザー画面とスタイル。HTTP APIで素材や抽選結果を取得する |
| `src/domain/` | ビンゴの成立条件、抽選、スタンプ、テーマのルール |
| `src/application/` | テーマ別の素材登録・スタンプ設定・抽選のユースケース |
| `src/interface/` | HTTPリクエストをユースケースに渡し、結果を返す |
| `src/infrastructure/` | ストレージと管理者セッションの実装 |

`worker.mjs` が各層を組み立てます。ローカル起動時は `local.mjs` がUIをビルドし、同じポートからUIとAPIを提供します。

## 遊び方

1. 管理画面で動物やスタンプの言葉を確認します。初期35種類には絵文字が入っていて、管理画面からイラストに差し替えられます。
2. 参加者は動物を9種類選んで好きなマスに置き、「あそぶ」を押します。
3. 管理者が抽選を開始し、「1種類引く」で表示された動物を読み上げます。
4. 参加者は当たったマスを押します。もう一度押すと取り消せます。縦・横・斜めに1列そろうとビンゴです。
5. 「カードを画像で保存」で、スタンプが入ったカードを PNG にできます。

端末に保存したカードはスタート画面から再開できます。動物と抽選の情報は、ホストの bingo-state.local.json に保存されます。抽選候補は管理者が抽選を開始した時点、スタンプの候補は参加者が「あそぶ」を押した時点で確定します。対面で読み上げを聞いて操作するゲームです。
